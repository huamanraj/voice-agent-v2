02 ARCHITECTURE PATTERN AND PROVIDER PORTS
==========================================

Pattern:
Use Ports and Adapters / Hexagonal Architecture.

Meaning:
The core agent depends on interfaces.
Provider adapters implement those interfaces.

Do not put provider-specific logic in the core.

Correct:
await telephony.clear_playback(reason="interruption")

Wrong:
await websocket.send_json({"event": "clearAudio"})

Required ports:
- TelephonyPort
- STTPort
- TTSPort
- LLMPort
- LiveStorePort
- FinalStorePort
- ObservabilityPort
- VADPort
- TurnDetectionPort
- MemoryPort optional

Folder:
src/voice_agent/contracts/ports.py

TelephonyPort:

class TelephonyPort:
    provider_name: str
    capabilities: TelephonyCapabilities

    async def start(self) -> None: ...
    async def receive_audio(self): ...
    async def send_audio(self, frame: AudioFrame) -> None: ...
    async def clear_playback(self, reason: str) -> None: ...
    async def send_checkpoint(self, checkpoint_id: str) -> None: ...
    async def playback_events(self): ...
    async def stop(self, reason: str) -> None: ...

STTPort:

class STTPort:
    provider_name: str
    capabilities: STTCapabilities

    async def start(self, call_id: str, language_hint: str | None = None) -> None: ...
    async def send_audio(self, frame: AudioFrame) -> None: ...
    async def transcripts(self): ...
    async def update_language_hint(self, language: str) -> None: ...
    async def stop(self) -> None: ...

TTSPort:

class TTSPort:
    provider_name: str
    capabilities: TTSCapabilities

    async def start(self, call_id: str, voice: str, language: str) -> None: ...
    async def synthesize(self, text: str, message_id: str, sequence_id: int): ...
    async def cancel(self, message_id: str, reason: str) -> None: ...
    async def stop(self) -> None: ...

LLMPort:

class LLMPort:
    provider_name: str
    capabilities: LLMCapabilities

    async def stream_response(self, call_id: str, messages: list, response_id: str): ...
    async def classify(self, call_id: str, prompt: str, schema: dict | None = None) -> dict: ...
    async def cancel(self, response_id: str) -> None: ...
    async def stop(self) -> None: ...

Capability objects:
TelephonyCapabilities:
- supports_clear_playback
- supports_playback_checkpoint
- supports_bidirectional_audio
- inbound_codec
- outbound_codec

STTCapabilities:
- supports_interim
- supports_final
- supports_vad_events
- supports_language_detection
- supports_code_switching
- accepted_codecs

TTSCapabilities:
- supports_streaming
- supports_cancel
- supports_word_timestamps
- output_codecs

LLMCapabilities:
- supports_streaming
- supports_json_mode
- supports_tool_calling

Provider registry:
src/voice_agent/factory/provider_registry.py

ProviderRegistry should register:
- telephony: vobiz, mock
- stt: deepgram, sarvam, mock
- tts: cartesia, sarvam, mock
- llm: litellm, mock
- storage: redis, postgres, memory
- observability: file, otel, noop

Config-driven provider selection:
TELEPHONY_PROVIDER=vobiz
STT_PROVIDER=deepgram
TTS_PROVIDER=cartesia
LLM_PROVIDER=litellm
LIVE_STORE_PROVIDER=redis
FINAL_STORE_PROVIDER=postgres
LOGGER_PROVIDER=file

Per-agent override:
An agent can override STT/TTS/LLM without changing core code.

Acceptance:
- Core imports only contracts, never provider files.
- Switching STT_PROVIDER from deepgram to sarvam does not touch core.
- Mock providers can run full call simulation without external APIs.
